# Omnes App

## Instalar dependências

```bash
bun install
```

## Rodar ambiente de desenvolvimento

```bash
bun run dev
```

O Vite irá abrir em:

```txt
http://localhost:5173
```

## Gerar build de produção

```bash
bun run build
```

Os arquivos finais ficarão em:

```txt
/dist
```



## Rodar preview da build

```bash
bun run preview
```
